# Магнитная сортировка

Браузерная головоломка, прототип 0.12.0 на Phaser 4.2.1.

Нажми на стопку: открытые конфеты одного цвета соберутся автоматически. Собери по четыре и очисти поле.

- Девять уровней, отмена и перезапуск; в уровнях 7–9 появляются цветные замки.
- Собери четыре конфеты цвета замка, чтобы открыть банку. Отмена восстанавливает замки.
- Управление мышью и касанием; на компьютере также 1–6, Z и R.
- Удержание показывает маршрут, увод пальца отменяет выбор.
- Кнопка «?» открывает помощь. Меню ☰ содержит уровни, звук и перезапуск.
- Анимация настраивается в меню: как на устройстве, полная или мягкая.

Это готовая статическая сборка. GitHub Pages публикует корень ветки main; файл .nojekyll отключает обработку Jekyll.
Глянцевые конфеты созданы с помощью image_gen; интерфейс, эффекты и процедурные звуки — собственные. Phaser распространяется по MIT: [лицензия](vendor/PHASER-LICENSE.md).
